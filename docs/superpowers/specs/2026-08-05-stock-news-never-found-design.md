# 個股查詢撈不到自己的新聞

日期：2026-08-05
起因：查 1453 大將，畫面顯示無新聞，但該檔近期確實有報導。

## 症狀

分析頁的「參考新聞」為空，且 summary 寫「由於近期無相關新聞報導，本分析係依據
產業知識進行評估」。對話一開始查 5439 高技的那張截圖也是同一句話 —— 當時以為
那是事實，實際上是假的。

## 根因

新聞管線是四層：Tavily 搜尋 → 網域白名單 → 標題相關性比對 → 取前四。
逐層印出進出後，斷點在**第一層**，不是過濾層。

查 1453 時送給 Tavily 的字串是：

```
大將 1453 紡織纖維 台股 供應鏈 競爭對手
```

回傳的六筆：

| 標題 | 提到大將？ |
|---|---|
| 紡織循環戰升溫 台廠技術突圍紅色供應鏈競合新局 | 否 |
| 紡織業「衣對衣」回收戰開打 | 否 |
| 「紡織業」的搜尋結果 - 工商時報 | 否（這是搜尋結果頁） |
| 「紡織」的搜尋結果 - 工商時報 | 否 |
| 「紡織廠」的搜尋結果 - 工商時報 | 否 |
| 日東紡擴產玻纖布 | 否 |

**標題與內文都沒有一筆提到大將或 1453。** 標題比對於是全數剔除 —— 那一層做的是
對的事，問題在它拿到的東西本來就不對。

查詢字串尾巴的「產業類別 台股 供應鏈 競爭對手」權重壓過了公司名，
Tavily 因此回傳整個產業的泛論與搜尋索引頁。

**同一個問題在 5439 高技上更明顯**：現況查詢回傳工商時報「上詮」「燿華」「敬鵬」
的搜尋結果頁；把尾巴拿掉後撈到五篇真報導（6 月營收創新高、Q3 賺回逾半個股本、
AI 伺服器高階板放量、低軌衛星、逆勢漲停解析）。不是 1453 特有的。

## 試過而否決的假設

**`topic: "news"` + `days: 30`。** 直覺上「要新聞就該指定 news」，實測回傳整頁
Palantir、Caterpillar、Visa 的美股英文新聞，完全無視中文查詢 —— 比現況更糟。
這個參數與 `include_domains` 併用時似乎會偏向 finance.yahoo.com 的美股 feed。

## 修法

### 1. 個股查詢字串

`stockNewsQuery(name, id)` → `${name} ${id} 股價 營運`

四種候選在 1453／5439／4906 三檔上實測：

| 查詢 | 過濾後的真報導數（三檔合計） | 品質 |
|---|---|---|
| `名 代號 股價 營運` | 2 / 5 / 5 | 最好：法說、轉型分析、族群報導 |
| `名 代號 營收 法人` | 3 / 5 / 3 | 4906 混進論壇與走勢圖頁 |
| `名 代號` | 0 / 1 / 1 | 幾乎全是行情頁 |
| `名 代號 新聞 營收` | 4 / 6 / 5 | 數量最多但幾乎全是自動生成的營收／盤中速報，把分析文章擠掉 |

同業改由 prompt 負責 —— 那裡已經給了官方產業類別並要求從中挑 2~4 家，
不需要靠搜尋字串去湊。

### 2. 剔除「不是報導」的頁面

`isNewsArticleUrl(url)`：路徑含 `/search/`、`/quote/`、`/twstock/`、
`/market-stock/`、`/company/`、`key-statistics` 者不是報導。

這批頁面（鉅亨個股總覽、工商時報行情頁、Yahoo 財務統計、TechNews 統一編號頁、
各家搜尋結果頁）標題確實有公司名與代號，會通過白名單也通過標題比對，
然後佔掉四個名額之一，並在畫面上變成一個點不出內容的連結。

**用排除法而非「路徑必須含 /news/」**：technews.tw 的報導網址是
`technews.tw/2026/07/09/slug/`，正面表列會把它一起擋掉。錯誤代價不對等 ——
漏擋一個行情頁只是浪費一格，誤擋一篇真報導是把這次分析唯一的依據丟掉。

## 已知殘留

排序仍以「標題命中幾個比對詞」為主鍵，而「盤中速報 - 正文(4906)急拉5.46%」
這類自動生成的稿子標題永遠同時含公司名與代號，因此拿到 2 分，排在
「正文轉型直供成效顯現毛利率走揚」（1 分）之前。

沒有一併處理：對 1453 這種小型股，速報是**唯一**的新聞，一律降權會讓它回到零篇。
要處理得先有證據支持某個降權規則，而不是憑感覺調權重。
